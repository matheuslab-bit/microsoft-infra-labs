# Checklist: entrada de colaborador

Copie para o chamado e vá marcando. O objetivo é a pessoa chegar no primeiro dia e conseguir trabalhar, com só os acessos que o cargo precisa.

## Antes do primeiro dia

- [ ] Chamado aberto pelo RH ou gestor, com nome, cargo, departamento, data de início e gestor
- [ ] Conta criada no padrão `nome.sobrenome` na OU do departamento ([`Import-LabUsers.ps1`](../../labs/02-active-directory/Import-LabUsers.ps1) para várias de uma vez)
- [ ] Senha inicial com troca obrigatória no primeiro logon
- [ ] Grupos do departamento (`GG_<departamento>`); acessos extras só com aprovação registrada do gestor
- [ ] Licença do Microsoft 365 e caixa de e-mail
- [ ] Ramal ou usuário de telefonia, se o cargo precisar
- [ ] Estação preparada: no domínio, na OU Estacoes, atualizada, com antivírus e BitLocker
- [ ] Equipamento registrado no inventário (patrimônio, número de série, responsável)

## No primeiro dia

- [ ] Primeiro logon acompanhado; troca de senha feita
- [ ] MFA configurado
- [ ] Acesso às pastas e sistemas testado com o próprio usuário
- [ ] Orientação rápida: como abrir chamado, política de senha, não salvar arquivos só na máquina

## Fechamento

- [ ] Termo de responsabilidade do equipamento assinado
- [ ] Chamado encerrado com a lista de acessos concedidos
